# FitPlan — только твои медиа

Эта версия содержит ровно 14 упражнений, привязанных к 12 GIF-анимациям и 2 статичным изображениям из присланного архива. Другие изображения и анимации удалены.

Открой `index.html` в браузере или опубликуй все файлы через GitHub Pages. GIF воспроизводятся нативно браузером и зацикливаются автоматически.

Примечание: для некоторых изображений упражнение определено по видимому движению; перед тренировкой сверь технику с иллюстрацией.
